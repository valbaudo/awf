# AWF v0.5.2 Release Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Prepare, merge, tag, publish, and verify AWF v0.5.2 as a patch release containing the Claude Code gated-readiness fixture and documentation.

**Architecture:** Release preparation is a changelog section plus the root install-version bump on the existing readiness branch. The branch is verified, fast-forwarded into `main`, verified again, and pushed before an immutable signed tag triggers the existing GitHub Actions release workflow. Publication is complete only after the workflow and all five release assets are verified.

**Tech Stack:** Git, signed annotated tags, Go 1.26, Make, GitHub Actions, GitHub CLI, SHA-256 release assets.

## Global Constraints

- Release version is exactly `v0.5.2`; `v0.5.1` and all published tags remain immutable.
- This is a patch release: no Go runtime, workflow format, schema, adapter, dependency, or packaging changes.
- The root README install block moves to `VERSION=0.5.2`; the live-tested readiness fixture remains honestly pinned to the v0.5.1 public archive.
- Do not disable the native sandbox or claim the macOS relative-state-path bug is fixed.
- Do not create or push a tag until feature-branch and merged-`main` `make lint test build` gates both pass.
- The release tag must be annotated and signed. If signing is unavailable, stop; do not substitute an unsigned tag.
- Push `main` before pushing `v0.5.2`, then monitor the tag-triggered `Release` workflow through publication.
- Once pushed, never move or delete `v0.5.2`; a bad release is superseded by a later patch.
- Preserve the separate `codex/permission-hardening` worktree and branch; they are unrelated to this release.
